## Installation

```bash
git clone https://github.com/abhaypratap0709/python-internship-projects.git
cd python-internship-projects

python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux/macOS
source .venv/bin/activate

pip install -r requirements.txt
```

## How to Run

Each project is self-contained inside its own folder with a `main.py` file:

```bash
cd Sysslan/Level-1/01-Grid-Display
python main.py
```
