# Level 4 — Console Applications

## Description

Full-featured, menu-driven console applications demonstrating structured program design and user interaction.

## Topics Covered

- Menu-driven application design
- Task management with status tracking
- File system operations (organizing files)
- Arithmetic operations with error handling
- Contact management (CRUD operations)

## Tasks

| # | Task                  | Description                              |
|---|-----------------------|------------------------------------------|
| 1 | Task Manager          | Add, view, complete, and delete tasks    |
| 2 | File Organizer        | Organize files by extension              |
| 3 | Calculator            | Basic arithmetic calculator              |
| 4 | Contact Book          | Manage contacts (add, search, delete)    |

## Learning Objective

Build complete, interactive applications with input validation and clean program flow.
