# Task Manager

## Description

A menu-driven console application to manage tasks with add, view, complete, and delete functionality.

## Features

- Add tasks with descriptions
- View all tasks with status indicators (✓/✗)
- Mark tasks as completed
- Delete tasks with confirmation
- Input validation

## Concepts Used

- Lists of dictionaries
- Menu-driven loop
- Index-based selection
- Boolean status tracking

## How to Run

```bash
python main.py
```

## Expected Output

Interactive task manager with options to manage a personal task list.
