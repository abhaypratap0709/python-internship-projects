# Calculator

## Description

A menu-driven console calculator that performs basic arithmetic operations.

## Features

- Addition, subtraction, multiplication, and division
- Handles division by zero
- Clean operation mapping using a dictionary
- Input validation

## Concepts Used

- Functions for each operation
- Dictionary-based dispatch
- Tuple return values
- Error handling

## How to Run

```bash
python main.py
```

## Expected Output

Prompts for an operation and two numbers, then displays the result.
