# Contact Book

## Description

A menu-driven console application to manage contacts with add, view, search, and delete operations.

## Features

- Add contacts with name and phone number
- View all contacts
- Search contacts by name (case-insensitive)
- Delete contacts with confirmation
- Duplicate name prevention

## Concepts Used

- Lists of dictionaries
- Case-insensitive search
- Index-based operations
- Input validation

## How to Run

```bash
python main.py
```

## Expected Output

Interactive contact book with options to manage a personal contact list.
