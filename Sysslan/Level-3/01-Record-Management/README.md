# Record Management

## Description

A simple in-memory record management system for adding and viewing name-age records.

## Features

- Add records with name and age
- View all records in a formatted table
- Input validation for name and age
- Menu-driven interface

## Concepts Used

- Lists of dictionaries
- String formatting
- Input validation
- Functions

## How to Run

```bash
python main.py
```

## Expected Output

Menu-driven interface to add and view records stored in memory.
