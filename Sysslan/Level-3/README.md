# Level 3 — File Handling & Logging

## Description

Tasks focused on reading, writing, and managing data using text files, with proper error handling.

## Topics Covered

- In-memory record management
- File persistence (read/write)
- File reading with error handling
- Logging with timestamps
- File I/O exceptions

## Tasks

| # | Task                      | Description                              |
|---|---------------------------|------------------------------------------|
| 1 | Record Management         | Add and view records in memory           |
| 2 | Save and Retrieve Records | Save records to a file and load them     |
| 3 | Read File                 | Read and display file contents safely    |
| 4 | Log File                  | Record timestamped messages to a log     |

## Learning Objective

Learn to persist data using files and handle I/O errors gracefully.
