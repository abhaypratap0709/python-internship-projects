# Log File

## Description

Records timestamped log messages to a file and provides options to view and clear the log.

## Features

- Write timestamped log messages
- View all log entries
- Clear the log file with confirmation
- Handles I/O errors

## Concepts Used

- `datetime` module for timestamps
- File append and write modes
- Error handling
- Confirmation prompts

## How to Run

```bash
python main.py
```

## Expected Output

Menu-driven interface to write, view, and clear log messages.
