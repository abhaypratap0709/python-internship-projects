# Save and Retrieve Records

## Description

Saves records to a text file and retrieves them, providing persistent storage across sessions.

## Features

- Add records (name and age) saved to `records.txt`
- View all records from the file
- Handles missing file and I/O errors
- Menu-driven interface

## Concepts Used

- File I/O (`open`, `read`, `write`)
- String parsing
- Error handling
- `os.path` for file checks

## How to Run

```bash
python main.py
```

## Expected Output

Menu-driven interface to save records to a file and view them later.
