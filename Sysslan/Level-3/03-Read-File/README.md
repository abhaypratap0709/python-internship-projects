# Read File

## Description

Reads and displays the contents of any user-specified text file with proper error handling.

## Features

- Prompts for a file path
- Displays file contents with formatting
- Handles file-not-found, permission, and I/O errors
- Detects empty files

## Concepts Used

- File reading (`open`, `read`)
- Exception handling (`FileNotFoundError`, `PermissionError`)
- Path input sanitization

## How to Run

```bash
python main.py
```

## Expected Output

Menu-driven interface that reads and displays the contents of a specified file.
