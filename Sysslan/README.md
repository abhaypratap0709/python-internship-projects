# Sysslan IT Solutions — Python Internship

This folder contains all tasks completed as part of the Python development internship at **Sysslan IT Solutions**.

## Overview

The internship is structured into **5 levels** with **20 tasks** in total. Each level builds upon the previous one, progressing from basic Python concepts to advanced applications.

## Levels

| Level   | Focus Area                       | Tasks |
|---------|----------------------------------|-------|
| Level 1 | Python Basics & Grids            | 4     |
| Level 2 | String Processing & Algorithms   | 4     |
| Level 3 | File Handling & Logging          | 4     |
| Level 4 | Console Applications             | 4     |
| Level 5 | Advanced Projects                | 4     |

## Topics Covered

- Variables, data types, and control flow
- Lists, dictionaries, and sets
- String manipulation and regular expressions
- File reading, writing, and persistence
- Error handling and input validation
- Menu-driven application design
- Web scraping, CSV processing, and automation

## Skills Practiced

- Writing clean, readable Python code
- Structuring programs with functions
- Following PEP 8 coding standards
- Handling edge cases and exceptions
- Using Python standard library modules
