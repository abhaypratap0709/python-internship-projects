# Password Generator

## Description

Generates strong random passwords with a mix of character types.

## Features

- User specifies password length (minimum 4)
- Guarantees at least one uppercase, lowercase, digit, and special character
- Shuffles characters for randomness

## Concepts Used

- `random` and `string` modules
- List operations and shuffling
- Input validation

## How to Run

```bash
python main.py
```

## Expected Output

Prompts for a length and displays a randomly generated password.
