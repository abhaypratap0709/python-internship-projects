# Level 2 — String Processing & Algorithms

## Description

Tasks involving string manipulation, input validation, random generation, and sequence algorithms.

## Topics Covered

- Regular expressions for validation
- Random password generation
- Text analysis (character and word counting)
- Fibonacci sequence generation
- Input validation and error handling

## Tasks

| # | Task                  | Description                              |
|---|-----------------------|------------------------------------------|
| 1 | Email Validator       | Validate email addresses using regex     |
| 2 | Password Generator    | Generate strong random passwords         |
| 3 | Text Analyzer         | Count characters and words in text       |
| 4 | Fibonacci             | Generate Fibonacci sequence for N terms  |

## Learning Objective

Strengthen skills in string operations, pattern matching, and algorithm implementation.
