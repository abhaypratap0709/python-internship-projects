# Fibonacci

## Description

Generates the Fibonacci sequence for a user-specified number of terms.

## Features

- Accepts the number of terms from the user
- Handles edge cases (0, 1, negative numbers)
- Displays the sequence in a comma-separated format

## Concepts Used

- While loops
- List operations
- Input validation

## How to Run

```bash
python main.py
```

## Expected Output

Displays the Fibonacci sequence for the requested number of terms.
