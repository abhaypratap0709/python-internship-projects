# Text Analyzer

## Description

Analyzes user-supplied text and displays character and word counts.

## Features

- Accepts text input in a loop
- Counts total characters (including spaces)
- Counts total words
- Handles empty input

## Concepts Used

- String methods (`len`, `split`)
- Tuple return values
- Input validation

## How to Run

```bash
python main.py
```

## Expected Output

Displays the total character count and word count for the entered text.
