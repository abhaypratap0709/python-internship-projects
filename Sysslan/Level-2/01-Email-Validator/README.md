# Email Validator

## Description

Validates email addresses using a regular expression pattern.

## Features

- Accepts email input in a loop
- Uses regex for pattern matching
- Displays ✅ or ❌ for valid/invalid emails
- Quit with `q`

## Concepts Used

- Regular expressions (`re` module)
- Input validation
- Loop-based interaction

## How to Run

```bash
python main.py
```

## Expected Output

Prompts for email addresses and reports whether each is valid or invalid.
