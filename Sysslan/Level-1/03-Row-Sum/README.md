# Row Sum

## Description

Calculates and displays the sum of each row in a 3×3 grid.

## Features

- Displays the grid
- Computes the sum of each row
- Prints results in a clear format

## Concepts Used

- List comprehension
- Built-in `sum()` function
- Enumeration

## How to Run

```bash
python main.py
```

## Expected Output

Displays the grid followed by the sum of each row.
