# Unique Numbers

## Description

Checks whether all numbers in a 3×3 grid are unique.

## Features

- Displays the grid
- Flattens the 2D list
- Compares list length to set length for uniqueness check

## Concepts Used

- List comprehension (flattening)
- Sets for duplicate detection
- Boolean logic

## How to Run

```bash
python main.py
```

## Expected Output

Displays the grid and reports whether all numbers are unique.
