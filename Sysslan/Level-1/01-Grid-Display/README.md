# Grid Display

## Description

Displays a 3×3 number grid in the console using a 2D list.

## Features

- Stores grid data in a nested list
- Prints rows in a clean, formatted layout

## Concepts Used

- 2D lists
- Loops and string formatting
- Functions

## How to Run

```bash
python main.py
```

## Expected Output

Prints a 3×3 grid of numbers (1–9) in aligned rows.
