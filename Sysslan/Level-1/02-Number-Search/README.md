# Number Search

## Description

Searches for a user-specified number within a 3×3 grid.

## Features

- Displays the grid before searching
- Prompts user for a target number
- Reports whether the number was found
- Handles invalid input

## Concepts Used

- 2D list traversal
- User input and validation
- Boolean return values

## How to Run

```bash
python main.py
```

## Expected Output

Displays the grid and reports if the entered number exists in it.
