# Level 1 — Python Basics & Grids

## Description

Introductory tasks focused on working with 2D lists (grids), basic iteration, and fundamental Python operations.

## Topics Covered

- 2D list creation and traversal
- Formatted console output
- Searching and filtering
- Aggregation (sum)
- Set operations (uniqueness check)

## Tasks

| # | Task                  | Description                              |
|---|-----------------------|------------------------------------------|
| 1 | Grid Display          | Display a 3×3 number grid                |
| 2 | Number Search         | Search for a number in a grid            |
| 3 | Row Sum               | Calculate the sum of each row            |
| 4 | Unique Numbers        | Check if all grid numbers are unique     |

## Learning Objective

Build confidence with Python lists, loops, and basic I/O operations.
