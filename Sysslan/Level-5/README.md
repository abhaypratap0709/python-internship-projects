# Level 5 — Advanced Projects

## Description

Advanced projects using external libraries, CSV processing, file system automation, and multi-utility tools.

## Topics Covered

- Web scraping with `requests` and `BeautifulSoup`
- CSV file reading and statistics
- Folder backup and file copying
- BMI, age, password, and unit conversion utilities
- Working with `datetime`, `shutil`, and `csv` modules

## Tasks

| # | Task                        | Description                              |
|---|-----------------------------|------------------------------------------|
| 1 | Basic Web Scraper           | Fetch and display webpage titles         |
| 2 | CSV Data Handling           | Read, search, and analyze CSV data       |
| 3 | Automated Folder Backup     | Create timestamped folder backups        |
| 4 | Mini Personal Utility Tool  | BMI, age, password, unit converter       |

## Learning Objective

Apply Python skills to real-world tasks involving external APIs, data processing, and automation.
