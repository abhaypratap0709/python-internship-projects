# Mini Personal Utility Tool

## Description

Combines four useful utilities into one menu-driven console application.

## Features

- **BMI Calculator** — calculates BMI and displays category
- **Age Calculator** — computes current age from birth date
- **Password Generator** — generates strong random passwords
- **Unit Converter** — converts temperature (°C/°F) and distance (km/miles)

## Concepts Used

- `datetime` module for date calculations
- `random` and `string` modules for password generation
- Mathematical formulas (BMI, unit conversion)
- Nested menus
- Input validation

## How to Run

```bash
python main.py
```

## Expected Output

Main menu with four utilities, each performing its specific calculation or generation.
